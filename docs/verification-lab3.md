# Проверка лабораторной № 3

Проверено 9 ноября 2026 года на production-сборке через `npm run preview` в Chromium. Скрипт: [tests/frontend_scenarios.py](../tests/frontend_scenarios.py). Команды его запуска — в [гайде № 3](guides/lab3.md). Backend и постоянное хранение frontend в этот этап не входят.

## Выполненные проверки

| Проверка | Результат |
| --- | --- |
| `npm run typecheck` | Ошибок TypeScript нет |
| `npm run lint` | Ошибок и предупреждений ESLint нет |
| `npm run build` | Сборка создана, предупреждений сборки нет |
| Основные переходы и прямые URL | Главная, история, создание, редактирование и 404 открываются |
| Добавление пяти типов | Записи появляются в истории, последние показатели обновляются |
| Валидация | Пустое поле, ноль, минус, текст, дробный пульс и пустая дата не сохраняются; фокус получает неверное поле |
| Дробные значения | Проверены точка и запятая |
| Редактирование | Поля предзаполнены; смена давления на вес очищает ненужные поля; ID и количество записей сохраняются |
| Отмена редактирования | Исходное значение не изменяется |
| Удаление | Отмена кнопкой и Escape сохраняют запись; подтверждение удаляет её и обновляет главную |
| Старая дата | Добавленная старая запись не подменяет более свежую карточку |
| Поиск и фильтр | Работают совместно, поиск не учитывает регистр и крайние пробелы; сброс восстанавливает список |
| Сортировка | Переключение между новыми и старыми меняет порядок |
| Пустые состояния | Отдельно проверены отсутствие совпадений, пустой ответ JSON и удаление последней записи |
| Ошибки загрузки | HTTP 500, повреждённый JSON и неправильная структура показывают экран ошибки |
| Повторная попытка | После снятия блокировки запрос выполняется снова и отображает данные |
| Загрузка | Задержанный запрос показывает индикатор, после ответа — журнал |
| Обновление страницы | Возвращаются 10 исходных записей; неизвестный ID редактирования показывает сообщение |
| Телефон | Создание, редактирование и удаление давления через мобильные карточки прошли |
| Адаптивность | На ширинах 320, 390, 768 и 1024 px у главной, истории и обеих форм нет горизонтальной прокрутки страницы |
| Клавиатура | Ссылка «К содержимому», фокус ошибочного поля, сохранение по Enter и закрытие диалога по Escape работают |
| Уменьшение движения | При `prefers-reduced-motion: reduce` анимация страницы отключается |
| Ошибки JavaScript | Необработанных ошибок `pageerror` в сценариях нет |

Ошибочные ответы и задержки создавались перехватом запросов в тестовом браузере. Файл демоданных и сервер при этом не менялись. Для снимков зафиксированы время 9 ноября 2026 года, 12:00 по Москве и часовой пояс Europe/Moscow. Это учебные записи, а не реальные медицинские данные. Другие браузеры не проверялись.

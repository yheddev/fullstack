# Проверка лабораторной работы № 1

Дата: 1 ноября 2026 года, Europe/Moscow.

Окружение: Node.js 24.19.0, npm 11.9.0, Chromium 154.0.8037.57. Браузерные сценарии выполнены автоматически через установленный в среде Playwright. Приложение запускалось локально через Vite dev на порту 5173 и Vite preview на порту 4173.

## Команды

| Команда | Итог |
| --- | --- |
| `npm install --no-audit --no-fund` | Зависимости установлены, создан `package-lock.json` |
| `npm run typecheck` | Код завершения 0 |
| `npm run lint` | Код завершения 0, ошибок и предупреждений нет |
| `npm run build` | Код завершения 0, ошибок и предупреждений нет |
| `npm run dev -- --port 5173 --strictPort` | Приложение запущено и проверено в браузере |
| `npm run preview -- --port 4173 --strictPort` | Production-сборка запущена и проверена в браузере |

При установке использовался временный npm-кеш в `work/`. Для новой установки по готовому lock-файлу предназначена команда `npm ci`, указанная в README.

## Браузерные сценарии

| Действие | Фактический результат |
| --- | --- |
| Прямо открыть `/`, `/measurements`, `/measurements/new` и обновить каждый адрес | Ответы HTTP 200, нужные экраны отображаются |
| Перейти по основным пунктам навигации | Экран и активный пункт меняются, состояние сохраняется между страницами |
| Открыть главную | Пять карточек последних показателей, пять последних записей |
| Открыть историю, выбрать «Пульс», затем «Все показатели» | Число записей меняется с 10 на 2 и обратно на 10, выбранный тип соблюдается |
| Добавить пульс 88, давление 127/83, температуру 36,8, сахар 5.7, вес 69.2 | Каждый тип сохраняется; переход в историю, уведомление и обновление соответствующей карточки работают |
| Добавить измерение со старой датой | Запись находится в конце истории, более свежий показатель на главной сохраняется |
| Отправить пустое поле значения | Ошибка «Введите значение», фокус на поле |
| Ввести 0, отрицательное число, текст, NaN, Infinity, 1e309, неправильную дробь и пробелы | Записи не создаются, поля помечены ошибкой |
| Ввести дробный пульс | Появляется требование целого положительного числа |
| Очистить дату | Появляется ошибка даты, фокус переводится на поле даты |
| Передать проверяющей функции 31 февраля, 13-й месяц, текст и нулевой год | Все неправильные даты отвергаются |
| Оставить обе части давления пустыми, затем указать дробное верхнее и нулевое нижнее давление | Ошибки проверяются отдельно для каждого поля |
| Ввести верхнее давление 120,0 и нижнее 80 | Сохраняется числовое значение 120/80 без NaN |
| Нажать «Отмена» в заполненной форме | Новая запись не создаётся |
| Обновить страницу после добавления записей | Возвращаются исходные десять демонстрационных записей |
| Открыть неизвестный адрес и нажать «На главную» | Показана страница 404, возврат работает |
| Нажать Tab после открытия, активировать «К содержимому» | Ссылка получает фокус; Enter переводит фокус на основную область |
| Изменить фильтр клавишами Enter и ArrowDown | Выбирается показатель, список обновляется |
| Открыть все три экрана при ширине 320, 390, 768 и 1024 px | Горизонтальной прокрутки страницы нет |
| Сохранить давление при ширине 320 и 390 px | Два поля помещаются по ширине, запись появляется в мобильной истории |
| Подставить пустой демонстрационный массив в тестовом браузере | В истории показано пустое состояние, на главной значения «—» и подписи «Пока нет записей» |
| Подставить только пульс и выбрать сахар | Показано сообщение «Измерений этого типа пока нет» |
| Следить за событиями `pageerror` и `console.error` | Ошибок приложения в проверенных сценариях нет |

Подмена массива использовалась только для двух проверок пустых состояний через перехват модуля в тестовом браузере. Приложение и демонстрационные исходники не изменялись, скрытые пользовательские функции очистки данных не добавлялись.

## Проверка production-сборки

Через `npm run preview` отдельно выполнены прямое открытие и обновление всех трёх экранов. Пульс 81 сохранён нажатием Enter на кнопке «Сохранить»: появилась 11-я запись, показалось уведомление, карточка на главной обновилась. Ошибок JavaScript и `console.error` не было.

Из этой же сборки сняты шесть настоящих скриншотов в `docs/screenshots/`. Картинки не генерировались и не имитируют интерфейс.

## Исправления по результатам проверки

- Убран автоматический перевод фокуса на главную область при первом открытии: он мешал первой ссылке навигации с клавиатуры. При смене маршрута перевод фокуса сохранён.
- Уменьшены промежутки мобильной навигации до ширины 380 px: устранена прокрутка на 320 px.
- Библиотеки React и Material UI выделены в отдельные файлы сборки: итоговая сборка проходит без предупреждения о большом единственном файле JavaScript.

На момент описанной локальной проверки другие браузеры и внешняя публикация не проверялись; коммиты и push не выполнялись по указанию пользователя. После завершения локальной части пользователь отдельно разрешил приватную публикацию через Sites, коммит и отправку исходников. Это отдельный этап после перечисленных проверок.
